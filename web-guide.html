最重要的三件事

做任何一個現場喜劇網頁，這三點都是硬性需求，不可省略：

  1. 投影位置可調整
    純文字看板可留白捲動，滿版介面可用上下位移，讓重點停在適合觀眾觀看的高度。
  2. 全螢幕功能與快捷鍵
    要有全螢幕按鈕，且所有操作都綁鍵盤快捷鍵（例如 F=全螢幕、空白鍵=下一個），因為現場常靠鍵盤盲操。
  3. 現場可調的參數控制台
    把可能要微調的參數做成網頁上的控制台＋自動記住，現場拉一拉就好，不用每次回來改程式碼。

有使用音效、音樂或特效，就必須提供控制台或網頁上可直接調整的選項，方便現場立即修改。

為什麼要這樣做

我們做的不是一般網站，而是現場演出的投影道具：在昏暗的場地用投影機打在布幕上、操作的人在側台用延伸螢幕常看不到滑鼠、後排觀眾視線會被擋、演出中沒時間 debug。所以原則是：大、簡單、靠鍵盤、容錯、可現場微調。

細節重點

1. 畫面佈局與彈性

  • 純文字看板可用留白捲動；滿版模擬介面可提供上下位移設定。重要內容靠上，避免被前排人頭或底部操作列擋住。
  • 重點文字用 vw／vh 定大小（如 min(8vw, 13vh)），換投影機解析度時字會自動縮放、不爆版。

2. 全螢幕與快捷鍵

  • 要有全螢幕按鈕（用 Fullscreen API，比 F11 穩）。全螢幕只能由使用者點擊／按鍵觸發，不能自動全螢幕。
  • 先偵測瀏覽器全螢幕功能，不支援時隱藏或停用按鈕；在正式設備上實測。
  • 每個按鈕都要有對應快捷鍵。按鈕是彩排用的，快捷鍵才是正式演出主力。
  • 擋按住連發與空白鍵捲動；輸入或調設定期間暫停演出快捷鍵，保留收合等必要操作。
  • 快捷鍵選單一字母或大鍵（空白／Enter／F），別用 Ctrl 組合（會被瀏覽器搶、跨系統行為不一）。

3. 視覺設計

  • 純文字看板適合黑底亮字；模擬 App 可保留情境配色與滿版背景，重點是清楚、可辨識。
  • 其他顏色可以，但以簡潔、不干擾為原則；投影機偏暗偏黃，要用高彩度高對比的顏色。
  • 控制台很重要：把要微調的參數做成面板＋localStorage 自動記住；可藏在小字裡點開，觀眾看不到、你隨時叫得出來。

其他實戰經驗

  • 依功能選架構：簡單工具可用單一 HTML，多頁與投稿工具可拆檔維護。即時投稿需要網路；已載入素材盡量保留，離線能力要實測，字體設系統備援。
  • 防呆：自動排除類的邏輯要想「條件太嚴格會不會卡死」並寫退路。
  • 手機也要測：排版自動縮、觸控優化。
  • 演出前清單：用正式設備＋投影機測、接延伸螢幕、走到最後一排看字、閉眼按快捷鍵、測捲動、斷網測、確認控制台設定有記住。
  • 發佈前檢查敏感資訊：API 金鑰、客戶名稱、內部連結、員工真名都不要推上公開 repo。

圖片：先載入、看得清楚

  • 原圖保留，網站使用壓縮副本；檢查色彩與方向，人物臉要清楚，提供裁切位置調整。
  • 舞台圖片提前下載、解碼，顯示目前／總數、完成與失敗數量；確認完成後再開始。
  • 投稿照片送出前縮尺寸、壓縮並限制大小。演出前可重新整理預載入，新投稿也更新進度。
  • 測試橫圖、直圖與超長圖；優先完整顯示，需要裁切時可調整位置。

內容與控制台：少字、好操作

  • 依企劃決定哪些文字出現，不擅加台詞、角色設定或姓名；操作提示放角落、小而低調。
  • 面板外能做的操作不用重複放；按鈕說明實際動作，按鈕大小、拉桿長度一致，同類設定放同一行。
  • 設定自動記住，點面板外可收合；底部按鈕位置穩定，未設定內容先顯示占位文字。

有聲音或特效：必須能現場調整

  • 只要使用音效、音樂或特效，就要有控制台或網頁上可直接調整的選項。不必每個企劃都加入這些功能。
  • 各聲音分別有音量與開關；特效依需要提供開關、強度或時間。準備立即停止的操作。
  • 自動播放觸發動作要明確，處理瀏覽器播放限制；定義音樂與音效能否同時播放。
  • 淡出設定分清楚等待時間與淡出過程時間，需要現場調整的值都放進設定。

有投稿：入口與管理清楚

  • 舞台、投稿與後台共用正式設定，正式／試玩清楚區分。試玩答案依目前題目產生，資料分開。
  • 觀眾頁只寫觀眾需要理解的文字；QR、投稿與後台連結用手機實測。
  • 後台最新投稿在前，可排序、分頁；忽略、封存、恢復清楚區分，保留原始資料，整批操作先確認。
  • 管理權限由伺服器驗證，不公開管理密碼；依人數及圖片流量確認服務額度。

發布與協作：同一份版本

  • 統一正式發布目錄，本機與 GitHub 同步；私有設定、原圖及封存檔依需要排除公開追蹤。
  • 多個 AI 協作先讀紀錄與 Git 差異，每次記錄修改與驗證，不覆蓋別人的未提交內容。
  • 更新 CSS／JS 資源版本避免舊快取；推送後確認公開網站部署完成，以及工具箱、投稿、後台與 QR 入口正確。
一句話總結：「暗場裡，一個看不到滑鼠的人，要能只靠鍵盤，把一行超大的字穩穩打在布幕上。」
清楚的投影內容、全鍵盤操作、預先載入與現場可調設定，都是為了讓演出順利進行。
