# 公開展示版

- GitHub：`allen365apple/jokes-on-me` 的 `簡報即興劇/` 子目錄。
- 公開版使用 `firebase-config.public.js` 作為 `firebase-config.js`，不連正式 Firebase。
- 投稿僅存在該瀏覽器，不能用於現場跨裝置收集。彩排請在控制台切換試玩題庫。
- 封存檔、待替換原圖、正式 Firebase 設定與內部協作歷史不發布。本機原檔全部保留。
- 現用成員姓名／照片、試玩照片與音效已由使用者確認可公開。
- 更新時只同步本專案子目錄，不覆蓋 repo 其他網站；先檢查敏感資料，再提交推送。
- 接正式資料庫前，需另外確認 Firebase Security Rules、操作人員權限及投稿防濫用；隱藏後台網址不等於權限保護。
