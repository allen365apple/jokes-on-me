# 公開展示版

- GitHub：`allen365apple/jokes-on-me` 的 `簡報即興劇/` 子目錄。
- 公開版使用 `firebase-config.js` 連到本專案的 Firebase Realtime Database room `jokes-on-me-live-2026`；資料讀寫由 Authentication 與 `database.rules.json` 保護。
- 正式投稿可跨裝置同步；彩排請在控制台或按 T 切換試玩題庫。後台需用 Firebase Email／Password 共用帳號登入。
- 封存檔、待替換原圖與內部協作歷史不發布。本機原檔全部保留。密碼不進入程式碼或 Git。
- 現用成員姓名／照片、試玩照片與音效已由使用者確認可公開。
- 更新時只同步本專案子目錄，不覆蓋 repo 其他網站；先檢查敏感資料，再提交推送。
- Firebase Security Rules 已限制 responses／moderation 的讀寫；正式演出仍建議不使用時關閉投稿，並留意匿名投稿的防洗版需求。隱藏後台網址不等於權限保護。
