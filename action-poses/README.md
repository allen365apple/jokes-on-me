# 看我動作片｜圖片放這裡

## 一個資料夾 = 一個回合

演出玩三回合，就是三個資料夾。資料夾名稱前面加數字可以決定順序：

```
1 動作／     ← 第 1 回合
2 動漫／     ← 第 2 回合
3 迷因／     ← 第 3 回合
```

回合名稱、數量都不是寫死的——**你在 Google Drive 開幾個子資料夾、取什麼名字，網頁就照著跑。**
之後想加第四回合，開第四個資料夾就好，程式不用改。

## 圖片從哪來？兩個地方，會疊在一起

| 來源 | 什麼時候用 | 角色 |
|---|---|---|
| **這個資料夾**（會上傳到網站） | 演出前用 `收圖.command` 從 Drive 收好 | **保底**。現場一定在，不靠網路 |
| **Google Drive** | 網頁開場時自動對照一次 | **加分**。Drive 上有、網站上還沒有的即時補進來 |

Drive 讀不到（沒網路、Google 抽風）就自動略過，用網站上這批照跑，**不會開天窗**。

## 平常怎麼操作

**演出前：對著 `收圖.command` 按兩下。** 就這樣。

它會：跟 Drive 對照 → 把新圖下載到這個資料夾 → 整理清單 → 上傳到網站。
跑完會列出每個回合各幾張，可以順便核對。

另外兩個檔案平常用不到：

- `上傳照片.command`：你自己手動把圖丟進資料夾時用（不碰 Drive，直接上傳）
- `更新清單.command`：只整理清單、不上傳，用在想先在自己電腦看效果的時候

## 檔名要怎麼取

**隨便取都可以。** 想讓某個回合可以「分類調比例」的話，才需要用「類別＋編號」：

| 檔名 | 效果 |
|---|---|
| `正經一.jpg`、`正經二.jpg`、`雙人一.jpg` | 自動分成「正經」「雙人」兩類，控制台可以分別調出現比例 |
| `鳴人結印.png`、`悟空龜派氣功.png` | 不分類，整個回合當成一類（動漫、迷因這種通常這樣就好） |

規則：**同一個前綴至少要有 2 張才算一類**，只有一張的不會自成一類。
編號用中文數字（一、二、…、三十）或阿拉伯數字（1、02、12）都可以。

想改類別名稱？改檔名就好，程式裡沒有寫死任何類別名。

> 檔名後面空一格再寫的字（例 `荒謬二 高抬腿踢.jpg`），只會出現在網頁的「動作清單」上方便自己對照。
> **投影畫面上永遠不會有文字，只有圖。**

## 拍攝／選圖建議

- **直式**構圖，人物全身完整入鏡，四肢不要被裁掉
- 純色背景或去背，投影在黑底上才乾淨
- 雙人動作兩個人都要完整入鏡
- 長邊 1200～1600px 就夠投影用，檔案不用太大
