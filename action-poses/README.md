# 看我動作片｜動作照片放這裡

把拍好的動作照片丟進這個資料夾，網頁就會用照片取代火柴人。**程式一行都不用改。**

## 檔名怎麼取

```
類別 + 編號 .jpg
```

例如：

| 檔名 | 網頁讀到的結果 |
|---|---|
| `正經一.jpg` | 類別「正經」第 1 張 |
| `雙人3.jpg` | 類別「雙人」第 3 張 |
| `荒謬十二.png` | 類別「荒謬」第 12 張 |
| `荒謬二 高抬腿踢.jpg` | 類別「荒謬」第 2 張，動作清單上標「高抬腿踢」 |

- **編號**：中文數字（一、二、…、三十）或阿拉伯數字（1、02、12）都可以
- **動作名稱**：可寫可不寫，寫了只會出現在網頁的「動作清單」上，方便自己對照。
  **投影畫面上不會出現任何文字，只有圖**——照片本身就是要模仿的動作
- **副檔名**：`.jpg` `.png` `.webp` 都可以
- 不用一次放滿，放幾張換幾張；沒被照片取代的部分繼續用火柴人

## 類別名稱可以隨時改

程式裡**沒有寫死任何類別名稱**——類別完全從檔名讀出來。

不想叫「正經」了？把 `正經一.jpg` 改成 `認真一.jpg`，重跑一次下面的更新清單，
控制台的比例滑桿就會自動變成「認真」。新增第四、第五個類別也一樣，直接用新的檔名前綴就好。

## ⚠️ 放好照片之後，要做這一步

**在 Finder 裡對著 `上傳照片.command` 按兩下。**

它會一次做完：掃描照片產生清單 → 上傳到 GitHub → 網站約 1 分鐘後自動換圖。
每次新增、改名、刪除照片之後都要再跑一次（跑完會列出目前有幾張，可以順便核對）。

> 旁邊還有一個 `更新清單.command`，那個只產生清單、不上傳，
> 用在「只想在自己電腦上先看看效果」的時候。平常用 `上傳照片.command` 就好。

為什麼需要這一步？靜態網頁沒辦法自己看資料夾裡有什麼，要靠 `清單.txt` 才知道有哪些照片。
（真的忘了跑也還有救：照片只要上了 GitHub，網頁會自動去問 GitHub 這個資料夾裡有什麼。）

## 拍攝建議

- **直式**構圖，人物全身完整入鏡，四肢不要被裁掉
- **純色背景**（白牆或黑幕）或去背，投影在黑底上才乾淨
- 雙人動作記得兩個人都要完整入鏡，左右留白
- 檔案不用太大，長邊 1200～1600px 就夠投影用了

## 目前內建的火柴人動作

打開 [action-draw.html](../action-draw.html) 點下方的「**動作清單**」，
會看到全部動作的示意圖與分類，可以直接當拍攝腳本。照片放進來之後，
對應的卡片會變成照片並標上 📷。

內建火柴人：正經 10 個、雙人 10 個、荒謬 10 個。
想改火柴人的名稱或增減，在 `action-draw.html` 裡搜尋 `const POSES`。
