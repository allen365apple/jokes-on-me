# 演員照片

這裡同時保存目前使用的照片與之後準備替換的新圖。未被程式引用不代表無用，整理時請保留。

目前選角頁已套用各原圖的 `.web.jpg` 輕量副本：`傑哥 新圖.png`（目前角色名稱為老闆）、`柏文 新圖.JPG`、`芭樂 新圖.jpg`、`巧達 新圖.JPG`、`又又 新圖.jpg`、`大弋 新圖.jpg`、`竹節蟲 新圖.jpg`。後續新照片也可放在這裡。

網站目前使用的照片由根目錄 `cast-config.js` 指定；放入新圖不會自動替換角色。正式替換時可另產輕量副本並調整取景，保留新圖原檔。

`story-avatar.png` 為歷史限動頭像素材，仍保留；目前限動頭像已改由 CSS 繪製。
